# 🏫 ClassFlow - AI-Powered School & Institution Management Platform

ClassFlow is a modern, responsive web application built for educational institutions, designed to seamlessly manage academic workflows, student tracking, and faculty operations with a sleek, role-based user interface.

## ✨ Key Features

* **Role-Based Dynamic Dashboards:** Instantly toggle between **Student** and **Teacher** views to experience tailored workflows for each user type.
* **Student View:** 
  * Real-time tracking of attendance percentages and roll numbers.
  * Interactive daily class schedules and lecture timelines.
  * Active assignment tracking and submission management cards.
* **Teacher View:**
  * Batch and department management metrics (assigned classes, enrolled student counts).
  * Quick-action **Attendance Marker** allowing faculty to toggle student presence (Present/Absent) dynamically per lecture batch.
* **Modern UI/UX:** Built with a clean, professional design system leveraging Tailwind CSS, Lucide icons, and a responsive grid layout.

---

## 🛠️ Tech Stack

* **Frontend:** React (JSX), Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Deployment Ready:** Configured for rapid deployment via Vercel
